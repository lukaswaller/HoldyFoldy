# Holdyfoldy

Live stock portfolio tracker with privacy-first viewing modes: real-time quotes, clean purchase/lot tracking, and one-tap modes that hide your dollar amounts so you can check your portfolio anywhere.

**Status:** Planning complete (vision, research, architecture, UI/UX). Build not started.
